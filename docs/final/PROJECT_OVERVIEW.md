# Project overview

This isolated Phase 3 branch continues the parametric FreeCAD geometry, Gmsh quadratic tetrahedral meshing, CalculiX static FEA, reference-engine loading, grouped ML and measured-CAD-mass optimization work from Phases 1 and 2. New evidence includes original raw-field recovery, deterministic full-thickness local refinement, CAD-linked hotspot auditing, flat and curved contact benchmarks, a 40-geometry feasibility screen and 12-geometry coarse/intermediate/fine paired datasets.

The primary design cases are 28 kN compression and 18 kN tension using a COSINE_BEARING equivalent-pressure model. Isotropic 4340 properties use E = 205 GPa, ν = 0.29 and density 7,850 kg/m³; 710 MPa yield remains an assumption pending a material certificate. At the finest solved baseline mesh (0.35 mm local transition target), compression/tension peak stresses are 566.718/770.139 MPa against a 394.444 MPa allowable. Both displacements (0.0991/0.1761 mm) are below 0.35 mm. Baseline peaks pass a provisional two-step <5% successive-change screen, but nonnested meshes and the unsolved 0.25 mm case limit the convergence claim.

No feasible candidate was found in 40 sampled geometries. Candidate 4 weighs 690.247 g and fails the fine-screen tension requirement at 501.358 MPa. The paired fine dataset has 24 analyses from 12 geometry groups; the validation-selected MLP has held-out stress MAE 208.86 MPa and R² 0.031 across only three test geometries. It is marked exploratory, and optimizer execution is guarded. No feasible optimized design or new weight reduction is claimed; the bounded search remains inconclusive rather than proof of global infeasibility.

Phase 1's reported 47.668% mass reduction remains historical, tied to sharp-pocket geometry, clamped-bore loading and mesh-dependent verification. It is not carried forward as a Phase 3 result.
