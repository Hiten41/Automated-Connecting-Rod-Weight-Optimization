# Feasibility and constraint margins

## Acceptance rules

All candidates use the same project limits: 28 kN compression, 18 kN tension, 710 MPa historical yield, FoS ≥1.8 (allowable 394.444 MPa), displacement ≤0.35 mm and linear buckling factor ≥1.8. The stress measure is maximum unaveraged integration-point von Mises stress. Coarse 6 mm results are screening data only.

## Status

`P4-0065` is the lowest-mass candidate satisfying the evaluated stress, displacement, buckling and provisional last-pair mesh-trend checks among the refined set. This is not a global optimum or production certification. The uncertainty of the bearing approximation, material condition, nonnested mesh sequence and lack of fatigue evidence remain.
